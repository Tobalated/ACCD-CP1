Embodied Motion

Embodied Motion is a high-fidelity interactive prototype that translates subtle human movement into an ambient visual system using real-time machine learning.

Built with p5.js and ml5.js, the project prioritizes look and feel while remaining technically real, stable, and fully functional. The scope is intentionally limited to a single interaction loop to ensure completion and clarity.

Sketches & Iterations

Early sketches explored direct visualizations of PoseNet data, including skeletal overlays and keypoint mappings. Through iteration, the system was simplified to focus on a small set of reliable signals, allowing the experience to move from raw data display to expressive interaction.

Each iteration reduced noise, clarified intent, and improved visual calmness.

Live Demo

The live prototype uses webcam input to track hand movement and translate distance and motion into particle flow. All interactions are real-time and unsimulated.

Reflection

Designing with machine learning required a shift from controlling outcomes to shaping relationships. By limiting scope and committing to one interaction loop, the prototype evolved from exploration into a cohesive, finished experience.
