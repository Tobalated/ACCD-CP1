Concept Overview

This experiment investigates how physical movement can control a digital environment. Instead of using traditional controllers, the prototype maps gestures (via camera input) or simulated directional input (via mouse/keyboard) into responsive on-screen behavior.

Core Focus

  • Detect directional input (left / right / up / down or gesture)
  • Translate movement into behavior (move, scale, rotate)
  • Design responsive feedback (visual cues that confirm control)
  • Tune sensitivity + delay to test perceived control

This is not a full game — it’s a single-feature interaction study.

Experiments

Experiment 1: Mouse Input

Use mouse/keyboard direction as a controlled baseline to validate mapping, responsiveness, and feedback clarity.

Experiment 2: Camera Input

Use camera-based gesture detection to explore real movement control and compare how it affects usability, timing, and emotional impact.

Expected Outcome

  • A playable prototype where motion triggers real-time environmental response
  • Clear feedback that communicates system state (success, error, active input)
  • Adjustable parameters for sensitivity and delay testing

Evaluation Questions

What feels intuitive? Where does delay break the sense of control? Which feedback signals reduce confusion? How does camera input change the emotional feel compared to mouse input?
