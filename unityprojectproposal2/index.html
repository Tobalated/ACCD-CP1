Unstable Balance

Unity Project Documentation

1. Project Overview

Unstable Balance is a physics-based Unity prototype where the player must maintain balance on a shaking platform while avoiding and managing falling objects. Unlike a traditional balancing game, objects first approach from the sides before dropping onto the platform, creating unpredictability and tension.

The player must continuously tilt the platform to control the movement of incoming objects and prevent them from falling off. Every object that falls off the platform causes the player to lose a life, making the experience more intense and challenging.

2. Project Objective

The objective of this project is to explore how motion-based controls affect player decision-making and reaction time in an unstable environment.

  • Motion-to-action mapping
  • Environmental instability through platform shaking
  • Reaction-based gameplay
  • Physics-driven object interaction
  • Risk and consequence through a life-loss system

3. Gameplay Description

The player stands on a central platform that continuously shakes, making balance harder to maintain. Different objects appear from the sides of the screen, move toward the player, and then drop onto the platform.

The player must tilt the platform left or right to manage these objects and keep them from falling off. As the game progresses, the pressure increases due to continuous object drops and platform instability.

Game Over Condition: The game ends when the player loses all lives.

4. Core Interaction Design

The interaction system is based on movement-driven control. The player influences the platform’s rotation, which directly affects how objects slide, roll, and collide.

Input Action
Left Arrow Key Tilt platform left
Right Arrow Key Tilt platform right

5. Game Mechanics

  • Platform Tilt: The player rotates the platform left or right.
  • Platform Shake: The platform shakes continuously to add instability.
  • Side Entry Objects: Objects enter from the sides before dropping.
  • Physics Interaction: Objects respond to gravity, tilt, and collision.
  • Life System: Every object that falls off costs one life.

6. System Behavior

The game system operates in several stages:

  • Object Generation: Objects spawn from the left or right side.
  • Movement Phase: Objects move horizontally toward the player.
  • Drop Phase: Objects fall onto the platform.
  • Physics Phase: Gravity and platform tilt determine movement.
  • Failure Check: If an object falls off, one life is removed.

7. Unity Components Used

Component Purpose
Rigidbody Enables gravity and realistic object movement
Box Collider Detects collision with the platform
Sphere/Cube Collider Allows falling objects to interact with surfaces
Transform Controls rotation and object movement
C# Scripts Handles platform tilt, spawning, shaking, and lives
UI Text Displays lives remaining and game status

8. Technical Implementation

The technical structure of the game relies on separate scripts for movement, instability, spawning, and life tracking.

  • Platform Control Script: Detects player input and rotates the platform.
  • Shake Script: Applies small random movement or rotation to simulate instability.
  • Spawn Script: Creates objects from side positions and sends them toward the platform.
  • Life System Script: Reduces lives when objects fall off and triggers game over.

9. Player Feedback

The game provides immediate visual feedback to help the player understand the system state:

  • Platform shaking communicates instability
  • Incoming side objects create anticipation
  • Falling objects show the result of poor balance
  • The life counter reflects performance and risk

10. Design Challenges

Some of the key challenges during development include:

  • Balancing the strength of the platform shake
  • Timing the spawn rate of incoming objects
  • Preventing physics glitches when multiple objects collide
  • Maintaining smooth and responsive platform controls

11. Future Improvements

  • Add different object sizes, shapes, and weights
  • Increase difficulty over time
  • Introduce sound effects and particle effects
  • Add a score system
  • Support gesture-based controls using camera input

12. Conclusion

Unstable Balance demonstrates how simple motion controls combined with environmental instability can create engaging and challenging gameplay. By introducing objects that approach from the sides, drop unpredictably, and threaten the player’s lives, the project becomes more dynamic and suspenseful.

The prototype shows how motion, timing, and visual feedback can shape interactive digital experiences in Unity.
